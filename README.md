# Builder_ai

## 🎯 The Problem
Building a full-stack web application from scratch takes days or weeks of setup, coding, and debugging. Non-technical founders and students often struggle to turn their ideas into working prototypes quickly.

## 💡 The Solution
Builder_ai is an open-source AI-powered web application builder. Users can simply type a prompt describing the app they want, and the AI generates the front-end and back-end structure, giving them a working prototype instantly.

## 🚀 How to Run Locally
1. Clone the repo: `git clone https://github.com/AbdulRehman-Ahmad/Builder_ai.git`
2. Navigate to the client folder: `cd client`
3. Install dependencies: `npm install`
4. Start the frontend: `npm run dev`
5. Navigate to the server folder: `cd ../server`
6. Install dependencies: `npm install`
7. Start the backend: `npm start` (or `node index.js`)
